Ниже приведён текст документа с мерами безопасности при работе на авиационной технике (выписка из Руководства по технической эксплуатации или аналогичного регламентирующего документа).

Разбей документ на отдельные записи — по одной на каждый пункт (меру безопасности):

1. `id` — обозначение пункта, как в документе (например, "РЭ п. 2.1"). Если документ не содержит нумерации, присвой порядковые обозначения "п. 1", "п. 2", …
2. `systems` — системы воздушного судна или виды работ, к которым мера относится: "электросистема", "гидросистема", "топливная система", "система управления", "силовая установка", "шасси", "общие работы", "работы на высоте" и т. п. Если мера общая для любых работ — укажи ["общие работы"].
3. `text` — полный текст меры, дословно.
4. `markers` — ключевые маркеры безопасности, содержащиеся в мере: критические действия, которые должны упоминаться в технологических картах. Типовые маркеры: "обесточить", "заземлить", "стравить давление", "заблокировать", "зашвартовать", "поставить колодки", "законтрить", "отсоединить питание". Приводи маркеры в неопределённой форме глагола. Если мера не содержит таких действий — пустой список.

Ответ — строго один JSON-объект вида:

{
  "records": [
    {"id": "РЭ п. 2.1", "systems": ["электросистема"], "text": "полный текст меры", "markers": ["обесточить"]}
  ]
}
